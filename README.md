# DairyIQ

DairyIQ is a Flask-based proof-of-concept decision-support system for raw cow
milk quality classification. It aligns the current software implementation with
the approved thesis direction: a Random Forest model, an 11-feature input
contract, and `Low`, `Medium`, `High` prediction labels.

The system is intended to support dairy processing plant staff with structured
milk-batch recording, model-assisted quality classification, standards-based
observations, history views, and basic analytics. It does not provide automatic
regulatory certification and does not replace laboratory judgment or real plant
validation.

## Approved Model Contract

The production model uses exactly these 11 features:

1. `pH`
2. `Temperature`
3. `Taste`
4. `Odor`
5. `Fat_Content`
6. `Titratable_Acidity`
7. `Protein_Content`
8. `Lactose_Content`
9. `TPC`
10. `SCC`
11. `Color`

The supported prediction labels are:

- `Low`
- `Medium`
- `High`

`SNF` is not a model input. `Turbidity` is not part of the approved thesis
feature contract.

## Standards and Sources

Primary source:

- `US EAS 67:2023`

Supplementary sources:

- Codex CXC 57-2004 / CAC/RCP 57 for temperature handling guidance.
- FAO milk composition reference ranges for protein and lactose.

Configured thresholds are documented in
[docs/standards-configuration.md](docs/standards-configuration.md).

## Current Dataset

The current model is trained on a reproducible synthesized dataset:

- path: `data/milk_quality_eas67_2023_synth_1500.csv`
- rows: `1,500`
- classes: `500 Low`, `500 Medium`, `500 High`
- generated by: `scripts/generate_dataset.py`

The synthesized dataset is for thesis prototype development and repeatable
evaluation. It does not replace validation using real plant measurements.

## Run Locally

Create and activate a virtual environment, then install dependencies:

```bash
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

Create local environment values in `.env`:

```env
FIREBASE_API_KEY=your-firebase-web-api-key
FLASK_SECRET_KEY=your-local-secret
FIREBASE_CREDENTIALS_PATH=firebase/firebase_key.json
```

Run the app from the project root:

```bash
python app/main.py
```

Open:

```text
http://127.0.0.1:5000
```

## Rebuild Dataset, Evaluation, and Artifact

Generate the dataset:

```bash
python scripts/generate_dataset.py
```

Train and evaluate models:

```bash
python scripts/train_evaluate.py
```

Build the production artifact:

```bash
python scripts/build_model_artifact.py
```

Run tests:

```bash
python -m pytest tests
```

## Important Limitations

DairyIQ is a proof-of-concept decision-support prototype. The current dataset is
synthetic, standards-bounded, and reproducible, but it is not a substitute for
real plant data collection, laboratory validation, user validation, or
regulatory approval.

Taste assessment must follow a safe approved protocol. The software must not
instruct operators to consume unsafe raw milk.
