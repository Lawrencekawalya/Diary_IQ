# Dataset Generation

The Phase 4 dataset is generated by:

`scripts/generate_dataset.py`

Run from the repository root:

```bash
python scripts/generate_dataset.py
```

## Outputs

Dataset:

`data/milk_quality_eas67_2023_synth_1500.csv`

Metadata:

`data/milk_quality_eas67_2023_synth_1500.metadata.json`

## Dataset Contract

The generated dataset contains:

- 1,500 rows
- 500 `Low` samples
- 500 `Medium` samples
- 500 `High` samples
- exactly 11 approved model features
- one target column: `Label`

Column order:

1. `pH`
2. `Temperature`
3. `Taste`
4. `Odor`
5. `Fat_Content`
6. `Titratable_Acidity`
7. `Protein_Content`
8. `Lactose_Content`
9. `TPC`
10. `SCC`
11. `Color`
12. `Label`

## Generation Policy

`High` records are generated within configured standards and normal sensory
values.

`Medium` records contain mild numeric deviations and occasional sensory defects.

`Low` records contain clear numeric failures and at least one sensory defect.

The generator uses deterministic random seed `20260718`.

## Sources

Primary source:

- `US EAS 67:2023`

Supplementary sources:

- Codex CXC 57-2004 / CAC/RCP 57 milk hygiene guidance for temperature.
- FAO milk composition reference ranges for protein and lactose.

Protein and lactose are composition-reference ranges, not direct legal
acceptance limits under `US EAS 67:2023`.

## Validation

The generator validates:

- approved columns only
- no missing values
- valid labels only
- 500 rows per class
- no duplicate feature rows
- no impossible numeric values
- sensory values encoded only as `0` or `1`

`SNF` and `Turbidity` are intentionally excluded from the model dataset because
they are not part of the approved 11-feature thesis contract.
